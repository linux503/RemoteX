# RemoteX visual world

- **Modes:** website = Persuade; desktop app = Operate.
- **Language:** cold zinc surfaces, one rose accent (`#c2414a`), Outfit + PingFang / Noto Sans SC.
- **Shape:** 12px controls, 16px cards, pill only for status chips.
- **Motion:** hero entrance on the site; hover only in the app. No mesh blobs, no gradient text, no emoji icons.
- **Copy:** product verbs. No "redefined", no em-dashes.
- **Dials:** site 7 / 5 / 3; app 4 / 2 / 5.
